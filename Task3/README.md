# Список требований для внешних интеграций

## Требования к безопасности
1. Соединения с внешней платформой "Умный дом" должны использовать аутентификацию.
2. Для аутентификации пользователей (собственников, сотрудников, менеджеров) необходимо использовать MFA.
3. Для аудита журналов безопасности и выявления аномалий необходимо интегрировать SIEM-систему.
4. Использование защищенного изолированного контура для систем, в которых осуществляется обработка ПДн (в т.ч. биометрии)
5. Использование шифрования для явзаимодействия со всеми внешними сервисами (TLS 1.2+).
6. Соответстивие внешних систем требованиям ФЗ, в частности ФЗ-572 и ФЗ-152.

## Протоколы аутентификации и авторизации
Для аутентификации и авторизации как пользователей, так и внешних интеграций необходимо использовать протокол OAuth 2.0.

## Взаимодействие между системами предприятия и внешней платформой
1. Непосредственное взаимодействие с устройствами (домофоном, шлагбаумом) осуществляется внешней платформой.
2. Для передачи команд устройствам используется REST API внешней платформы.
3. `tenant-core-app` и `device-management-app` должны будут иметь API для обработки запросов от внешних систем.
4. Работа с биометрическими данными (идентификация, аутентификация) осуществляется внешней платформой.
